Como montar um plano de plantio escalonado

  1. Escolha a hortaliça e informe se vai começar pela semente ou por uma muda pronta, quando essa opção estiver disponível.
  2. Defina quanto quer colher por semana para casa e para vender. Compare a área estimada com o espaço útil dos canteiros.
  3. Salve o cultivo para reunir na agenda as datas previstas de cada lote. Use a colheita real para ajustar os próximos planos.

As datas são estimativas. Consulte o calendário de plantio por região para escolher o mês de início.

Quer visualizar as posições das plantas? Use o planejador de canteiros.
